# JobScope Deep Research

واجهة بحث ثنائية اللغة للبحث الوظيفي العميق والبحث العام متعدد المصادر.

## التشغيل

```bash
npm start
```

ثم افتح `http://localhost:3000`.

## ملاحظات مهمة

النسخة الأولى تعمل بلا مفاتيح API وتبني خريطة مصادر واستعلامات وتقريرًا محليًا قابلًا للطباعة إلى PDF. المصادر المحمية أو التي تتطلب تسجيل دخول لا يتم تجاوزها؛ تظهر كحالات manual/fallback. طبقة Supabase وFirebase جاهزة للإضافة بعد إنشاء الموارد وربط الأسرار في الخادم، دون تخزين بيانات شخصية.
